# لقطات شاشة المنصة

مأخوذة من حسابات العرض على <https://elhafazah-academy.vercel.app> بدقة عالية
(1440×900 بمضاعف ٢ — أي 2880×1800 بكسل، تصلح للنشر والطباعة).

**إعادة التوليد بعد أي تغيير:**

```bash
node scripts/screenshots.mjs
```

> تحتاج بيانات العرض موجودة أولاً: `node scripts/seed-showcase.mjs`

## ملاحظات قبل النشر

- اللقطات تُظهر بريد حساب العرض أسفل القائمة الجانبية
  (`m.abdulrahman@demo.elhafazah`). اقتصّ الجزء السفلي إن أردت إخفاءه.
- **لقطة المصحف** تحتاج أن تكون الخطوط قد حُمّلت — السكربت ينتظر ٤ ثوانٍ لها.
  لو ظهر النص بخط عادي بدل الخط العثماني، أعد التشغيل.
- عند تغيير الهوية لجهة مشترية، أعد توليد اللقطات بعد تطبيق شعارها وألوانها.
