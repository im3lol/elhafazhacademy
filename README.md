# أكاديمية الحفظة — Elhafazah Academy

منصّة تعليمية متكاملة لتحفيظ القرآن الكريم وتعليم التجويد، بثلاثة أدوار (طالب / معلم / أدمن).
عربية بالكامل (RTL)، وضع فاتح وداكن، وهوية بصرية بخط وألوان **ثمانية** (زمردي/ذهبي).

المشروع **مفتوح المصدر** برخصة [MIT](LICENSE) — خذه وشغّل أكاديميتك عليه.

> **تشغيل سريع محلياً:** `docker compose up -d --build` ثم `docker compose --profile seed run --rm seed` ← افتح **http://localhost:8080**

---

## 🕌 شغّل نسختك (Vercel + Supabase)

كل جهة تأخذ **نسخة مستقلة**: مستودعها، ومشروع Vercel خاص، وقاعدة Supabase خاصة،
وهوية ومحتوى خاصّان بها. لا بيانات مشتركة بين النسخ.

```
Fork للمستودع
  → Vercel: Import Git Repository → أضِف AUTH_SECRET و CRON_SECRET
  → تبويب Storage → Supabase → قاعدة جديدة، ثم Redeploy
  → البناء يطبّق المخطط ويبذر القرآن تلقائياً (~دقيقة)
  → /setup لإنشاء أول حساب إدارة (بريدك وكلمة مرورك — لا كلمة مرور افتراضية)
  → /admin/branding للاسم والشعار والألوان والمحتوى
```

فتحت الموقع قبل ربط القاعدة؟ صفحة `/setup` تعرض الخطوة الناقصة بالضبط.
وتغيير بريد الدخول وكلمة المرور لاحقاً من `/admin/account`.

**اعمل Fork، لا تعمل على هذا المستودع.** الـ Fork يبقي صلة `upstream`، فزر
**Sync fork** يسحب الإصلاحات لاحقاً بنقرة.

الدليل الكامل بالخطوات وقائمة التحقّق وكيفية سحب التحديثات:
**[docs/HANDOVER.md](docs/HANDOVER.md)**.

## ✨ المزايا حسب الدور

### 👨‍🎓 الطالب
- **المصحف الشخصي**: عارض صفحي (٦٠٤ صفحات، خط QCF الدقيق)، تشغيل تلاوة من أي كلمة مع تمييز الكلمة الجارية، تنقّل بالسور/الأجزاء، علامات مرجعية، وضع حفظ (تكرار مقطع).
- **رؤية الأخطاء**: الكلمات التي أخطأ فيها مُبرَزة على المصحف، و**popup عند الوقوف** عليها يُظهر نوع الخطأ وسببه.
- **صفحة «تقدّمي»**: خريطة الحفظ (شبكة الأجزاء)، النشاط والتقييم الشهري، إنجازات بسجلّ زمني، وتقرير قابل للطباعة/PDF.
- الدروس والتقارير، الأخطاء، حجز الحصص، الباقة والدفع، الشكاوى، الإشعارات.

### 👨‍🏫 المعلم
- لوحة تحليلية + **تنبيه الطلاب المتعثّرين**.
- **تقرير الحصة**: مصحف تفاعلي لتحديد المقطع المُدرَّس، و**كليك يمين على كلمة لإضافة خطأ** يُسجَّل تلقائياً في التقرير، مع الدرجات والملاحظات والواجب.
- **الغرفة المباشرة** أثناء الحصة: يَعرِض صفحة المصحف فيتابعها الطالب لحظياً، مؤشّر حضور حيّ، وتسجيل أخطاء (كليك/كليك يمين) تظهر للطالب فوراً وتُجمَّع تلقائياً في تقرير نفس الحصة.
- إدارة مصحف الطالب، الطلاب، الرصيد والمستحقات، طلبات الباقات/الطلاب الجدد.

### 🛡️ الأدمن
- لوحة تحليلية شاملة، إدارة الطلاب/المعلمين/الباقات/الحصص/القرّاء/الأدوار والصلاحيات.
- مراجعة المدفوعات والمالية وتصدير CSV، الشكاوى، الإشعارات.
- متابعة المصحف لكل طالب، وملف طالب كامل (تقدّم + مصحف + حصص).
- **الإعدادات من اللوحة**: بيانات Google (Client ID/Secret)، تيليجرام، وبيانات التحويل — بلا تعديل ملفات.

## 🐳 التشغيل بـ Docker (الطريقة الموصى بها)

يتطلّب **Docker Desktop**. المنظومة كاملة (Next.js + Postgres) في حاويات.

```bash
# 1) شغّل كل شيء (يبني التطبيق + يقيم Postgres، ويطبّق الـ schema تلقائياً أول مرة)
docker compose up -d --build

# 2) ابذُر البيانات مرّة واحدة: القرآن + حسابا العرض
#    (حساب الإدارة ليس هنا — يُنشأ من صفحة /setup في المتصفح)
docker compose --profile seed run --rm seed

# 3) افتح المتصفّح
#    http://localhost:8080
```

**أوامر مفيدة:**
```bash
docker compose down           # إيقاف (تبقى البيانات)
docker compose down -v        # إيقاف + مسح القاعدة (بداية نظيفة)
docker compose logs -f app    # سجلّ التطبيق
APP_PORT=9000 docker compose up -d   # تشغيل على منفذ آخر (Linux/macOS)
```
> Windows PowerShell لتغيير المنفذ: `$env:APP_PORT="9000"; docker compose up -d`

تفاصيل أوفى: **[docs/DOCKER.md](docs/DOCKER.md)**.

## 🔑 الدخول

**حساب الإدارة**: يُنشأ من صفحة `/setup` عند أول تشغيل — ببريد وكلمة مرور من
اختيارك. الصفحة تُغلق نفسها بعد أول أدمن. لا توجد كلمة مرور افتراضية في المستودع.

**حسابا العرض** (يُنشئهما `docker compose --profile seed run --rm seed`،
أو `node scripts/seed-demo.mjs` محلياً — للاستكشاف فقط):

| الدور | البريد | كلمة المرور |
|---|---|---|
| **معلم** | `teacher@demo.test` | `demo1234` |
| **طالب** | `student@demo.test` | `demo1234` |

> مفعّلان ومربوطان (الطالب لدى المعلم وعلى الباقة الأساسية).
> **احذفهما قبل أي استخدام حقيقي.**

## 🗄️ قاعدة البيانات والبذور

- **٣٥ جدولاً** (مستخدمون/أدوار، طلاب/معلمون، باقات/اشتراكات/مدفوعات، حصص/تقارير/أخطاء، مصحف/قرّاء/إنجازات، شكاوى/إشعارات/تدقيق…).
- ملفات `db/init/*.sql` يطبّقها `npm run setup` (وهو ضمن `npm run build`): `01_schema.sql`
  على قاعدة فارغة فقط، و`02`→`05` على كل نشرة — وهي قناة وصول التحديثات لأي نسخة منشورة
  ([التفاصيل](docs/DATABASE.md)).
- **بيانات القرآن** (آيات/كلمات/تخطيط) تُبذَر بسكربت (ضمن خطوة الـ seed) — بدونها المصحف فارغ.

| السكربت | الوظيفة |
|---|---|
| `setup` | **المخطط + الأدوار والباقات + القرآن** — آمن للتكرار، ويعمل ضمن `npm run build` |
| `seed:quran` / `seed:quran-layout` | نص القرآن + تخطيط الأسطر (QCF) منفردَين |
| `seed-admin.mjs` | حساب أدمن للطوارئ (المسار الطبيعي: صفحة `/setup`) |
| `seed-demo.mjs` / `seed-showcase.mjs` | بيانات تجريبية / بيانات عرض كاملة (`--clean` للحذف) |

تفاصيل أوفى: **[docs/DATABASE.md](docs/DATABASE.md)** · تشغيل نسختك: **[docs/HANDOVER.md](docs/HANDOVER.md)** · النسخ الاحتياطي: **[docs/BACKUP.md](docs/BACKUP.md)**.

## 💻 التشغيل المحلي (بدون حاوية التطبيق)

```bash
docker compose up -d db        # Postgres فقط
cp .env.local.example .env.local   # واضبط DATABASE_URL و AUTH_SECRET
npm install
npm run setup      # المخطط + الأدوار والباقات + القرآن (آمن للتكرار)
npm run dev        # http://localhost:3000 — ثم /setup لإنشاء حساب الإدارة
npm run build      # بناء إنتاجي
npm test           # اختبارات الوحدة (٤٨) — بلا قاعدة بيانات
npm run lint       # فحص الجودة

# اختبارات التكامل تكتب صفوفاً حقيقية، فتعمل على قاعدة اختبار وحدها:
TEST_DATABASE_URL=postgres://postgres:postgres@localhost:5433/elhafazah npm run test:db
```

## ⚙️ متغيّرات البيئة

| المتغيّر | إلزامي | الوصف |
|---|:---:|---|
| `DATABASE_URL` | ✅ | سلسلة اتصال Postgres (للإنتاج: Transaction pooler من Supabase — [التفاصيل](docs/DATABASE.md#supabase-الإنتاج)) |
| `AUTH_SECRET` | ✅ (إنتاج) | سرّ الجلسات — `openssl rand -base64 32` |
| `NEXT_PUBLIC_APP_URL` | ✅ | عنوان التطبيق (لروابط الاسترجاع/OAuth) |
| `CRON_SECRET` | موصى | حماية `/api/cron/tick` (تذكيرات + دورة حياة الحصص) |
| `BLOB_READ_WRITE_TOKEN` | إنتاج | تخزين الملفات على Vercel Blob (يُضبط تلقائياً عند ربط Blob) |
| `GOOGLE_*` | اختياري | بديل عن ضبط Google من لوحة الأدمن |

القالب الكامل: `.env.local.example`. النشر على Vercel: **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**.
